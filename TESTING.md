# Testing

Required layers:
- Unit tests
- Integration tests
- E2E tests
- Security tests
- Architecture fitness tests

Minimum coverage expectations:
- Authentication
- Authorization
- Tenant isolation
- Conflict checks
- Document access
- Search access
- Billing integrity
- Idempotency
- Webhook safety

CI expectations:
- Tests run on every merge candidate.
- Security scanning is part of CI.
