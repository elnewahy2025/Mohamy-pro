# Threat Model

Key threats to cover:
- Authentication attacks
- Tenant escape
- IDOR
- Privilege escalation
- File upload attacks
- Malware
- SSRF
- XSS
- CSRF
- SQL injection
- Command injection
- Webhook attacks
- Token theft
- Session fixation
- Credential stuffing
- Data exfiltration
- AI prompt injection
- AI tool abuse
- Public intake abuse
- Export abuse

Rule:
- The threat model must be updated when architecture changes materially.
