# AI Architecture

Position:
- AI is optional and must not become a dependency of the legal core.

Layers:
- AI Gateway
- AI Orchestrator
- Agents
- Retrieval
- Tools
- Policies
- Providers

Rules:
- AI access is permission-aware.
- AI data access must be scoped by tenant and authorization.
- AI memory is not a legal record.
- AI output does not become an official record without human approval.
- Provider-specific code stays outside the core domain.
