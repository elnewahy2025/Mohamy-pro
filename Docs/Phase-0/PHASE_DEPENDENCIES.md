# Phase Dependencies

Core dependency rules:
- Identity and multi-tenancy must exist before any tenant-scoped domain.
- Audit foundation begins before business-critical legal data grows.
- Conflict check must exist before matter or case acceptance.
- Time tracking must exist before billing.
- Document security must follow document management.
- Integration contracts must exist before provider-specific implementations.
- Backup baseline must exist in the foundation phase.

Examples:
- Billing depends on Time Tracking, Case, Client, Currency, Fee, and Payment foundations.
- AI depends on Authorization, Document Access, Search, and Integration Hub contracts.
- Client Portal depends on Identity, Authorization, Cases, Documents, and Communications.
