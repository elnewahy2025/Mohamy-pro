# Authorization Matrix

Purpose:
- Define the authoritative mapping between roles, permissions, resources, actions, scopes, and denials.

Required columns:
- Role
- Permission
- Resource
- Action
- Tenant scope
- Organization scope
- Branch scope
- Department scope
- Ownership
- Assignment
- Conditions
- Denials
- Delegation
- Approval requirement

Use:
- This matrix is the source for automated authorization tests.
